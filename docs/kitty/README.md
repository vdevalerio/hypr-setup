# Kitty

GPU terminal (`SUPER + Return`). Config: `~/.config/kitty/kitty.conf`; colors in
`colors.conf` (generated by the theme) and font size in `font.conf` (generated
by `look.sh`, `SUPER + ALT + = / - / 0`). Do not edit those two by hand.

Look: JetBrainsMono Nerd Font, 12 px padding, background opacity 0.78 (only the
background, text stays sharp; Hyprland blurs what is behind), beam cursor with a
trail, 10 000 lines of scrollback, powerline tab bar at the bottom.

## Shortcuts

| Keys                                | Action                                                   |
| ----------------------------------- | -------------------------------------------------------- |
| `Ctrl+Shift+T`                      | New tab                                                  |
| `Ctrl+Shift+Q`                      | Close tab                                                |
| `Ctrl+Shift+←/→`                    | Previous / next tab                                      |
| `Ctrl+Shift+Enter`                  | New split window                                         |
| `Ctrl+Shift+]` / `[`                | Next / previous window                                   |
| `Ctrl+Shift+C` / `V`                | Copy / paste (selecting already copies to the clipboard) |
| `Ctrl+Shift+=` / `-`                | Font size                                                |
| `Ctrl+Shift+F5`                     | Reload `kitty.conf`                                      |
| `Ctrl+Shift+A` then `M` / `L` / `D` | More / less opaque / default opacity                     |
| `Ctrl+Shift+H`                      | Scrollback in a pager                                    |
| `Ctrl+Shift+Delete`                 | Clear the terminal                                       |
| `Ctrl+Shift+F2`                     | Open `kitty.conf`                                        |

## Good to know

- On login, a shell prints `fastfetch` (only at the top-level kitty window; set
  `FASTFETCH_ON_START=0` to disable).
- `copy_on_select clipboard` means mouse selection goes straight to the system
  clipboard.
- Colors follow the system theme; running terminals reload on a theme change
  (`SIGUSR1`).
- Every terminal opens inside [tmux](../tmux/README.md): the `shell` option runs
  `scripts/tmux-start.sh`, which attaches to a restored session nobody is using,
  or starts a new one (plain zsh if tmux is missing). Apps started with
  `kitty -e` (yazi, btop…) are not affected.
