# Quickshell (lock screen and overview)

Qt/QML shell used for two things, in `~/.config/quickshell`:

- **Lock screen** (`lock.qml`, `LockSurface.qml`): animated wallpaper, profile
  picture, clock, music and battery. Started by `scripts/lock.sh`; falls back to
  `hyprlock`. `SUPER + Esc` locks.
- **Workspace overview** (`overview.qml`, `OverviewScreen.qml`): resident, toggled
  with `SUPER + Tab`; shows workspaces and windows of each monitor.

`Theme.qml` reads `colors.json` (generated by the theme script).

## Notes

- Icons need `//@ pragma IconTheme Papirus-Dark`.
- Live reload watches the files; editing with `sed -i` breaks the watcher, so
  restart the instance instead.
- Hyprland ignores focus dispatches while a layer holds exclusive keyboard focus:
  close the layer first and dispatch ~40 ms later.
