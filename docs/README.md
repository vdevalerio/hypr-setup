# hypr-setup docs

User guides for every application in the [hypr-setup](https://github.com/vdevalerio/hypr-setup)
desktop (Arch Linux + Hyprland). Each folder is one app: a `README.md` with the
overview and, for bigger apps, topic guides next to it.

| App | Folder |
| --- | --- |
| Neovim with LazyVim: explorer, buffers, search, LSP, git, formatting, data | [lazyvim](lazyvim/README.md) |
| Hyprland: keybindings, workspaces, session, scripts | [hyprland](hyprland/README.md) |
| Kitty terminal | [kitty](kitty/README.md) |
| tmux | [tmux](tmux/README.md) |
| To-do list | [todo](todo/README.md) |
| zsh and shell tools | [zsh](zsh/README.md), [tools](tools/README.md) |
| Yazi file manager | [yazi](yazi/README.md) |
| Lazygit | [lazygit](lazygit/README.md) |
| Rofi menus | [rofi](rofi/README.md) |
| Waybar | [waybar](waybar/README.md) |
| SwayNC notifications | [swaync](swaync/README.md) |
| Quickshell: lock screen and overview | [quickshell](quickshell/README.md) |
| fcitx5 input methods | [fcitx5](fcitx5/README.md) |
| Zathura, Foliate, mpv, imv | [readers](readers/README.md) |
| Themes, wallpapers, fonts | [theming](theming/README.md) |
| Install, update, backup, VM | [system](system/README.md) |

Conventions: `SUPER` is the logo key; `<leader>` in Neovim is `Space`; `PREFIX`
in tmux is `Ctrl+a`.

Keep these docs in sync when a binding or config changes (the live config is
the source of truth).
