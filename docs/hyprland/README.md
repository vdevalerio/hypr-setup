# Hyprland

Tiling Wayland compositor (Hyprland 0.56). The config is **Lua**, not
hyprlang, in `~/.config/hypr`.

| Guide | Covers |
| --- | --- |
| [Keybindings](keybindings.md) | Every shortcut, grouped |
| [Workspaces and monitors](workspaces-and-monitors.md) | Per-monitor workspaces, laptop lid, displays |
| [Session](session.md) | Lock screen, idle, power menu, battery, login |
| [Scripts](scripts.md) | What each helper in `hypr/scripts` does |
| [Configuration](configuration.md) | File layout, how to change and validate |

`SUPER + F1` opens a searchable list of every keybind (generated from the
config, so it is always current).
