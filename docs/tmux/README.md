# tmux

Terminal multiplexer for persistent sessions. Config:
`~/.config/tmux/tmux.conf`; colors are generated by `theme.py` into
`~/.config/tmux/colors.conf` (do not edit) and reloaded on theme change.

## Automatic start and restore

Nothing to run by hand:

- Hyprland starts the tmux server at login, and **tmux-continuum** restores the
  sessions saved before the reboot (windows, panes, folders and the text on screen).
- Every kitty terminal opens inside tmux (`scripts/tmux-start.sh`): it attaches to
  a restored session that nobody is using; when all are in use (or there are none)
  it opens a new session. Opening two terminals gives two sessions.
- continuum saves every 15 minutes, so a reboot can lose up to 15 minutes of
  layout changes. Save right now with `PREFIX Ctrl+s`; restore by hand with
  `PREFIX Ctrl+r`. Saves live in `~/.local/share/tmux/resurrect/`.
- Running programs are **not** resumed (Neovim, Claude, builds…), only the
  windows, directories and what was on the screen.
- The plugins (tmux-resurrect, tmux-continuum) are cloned into
  `~/.config/tmux/plugins/` by `./install.sh dotfiles` and are not part of the repo.
- To stop auto-restore, set `@continuum-restore` to `off` in `tmux.conf`.

## Prefix

The prefix is `Ctrl+a` (shown as `PREFIX`). `Ctrl+b` stays free for Neovim.
Press `PREFIX` and then the key.

## Sessions and windows

| Keys / command | Action |
| --- | --- |
| `tmux` / `tmux new -s name` | Start a session |
| `tmux ls` / `tmux a -t name` | List / attach |
| `PREFIX d` | Detach (session keeps running) |
| `PREFIX $` | Rename session |
| `PREFIX s` | Switch session |
| `PREFIX c` | New window (same directory) |
| `PREFIX ,` | Rename window |
| `PREFIX 1…9` | Go to window (numbering starts at 1) |
| `PREFIX n` / `p` | Next / previous window |
| `PREFIX &` | Close window |

## Panes

| Keys | Action |
| --- | --- |
| `PREFIX \|` | Split left/right (same directory) |
| `PREFIX -` | Split top/bottom (same directory) |
| `PREFIX h/j/k/l` | Move between panes |
| `PREFIX H/J/K/L` | Resize (repeatable) |
| `PREFIX z` | Zoom a pane (toggle) |
| `PREFIX x` | Close pane |
| `PREFIX {` / `}` | Swap panes |
| `PREFIX space` | Cycle layouts |

## Copy mode (vi keys)

`PREFIX [` enters copy mode; move with `h/j/k/l`, `/` searches, `v` starts a
selection, `y` copies and exits (to the system clipboard through OSC 52),
`q` leaves. The mouse works too: scroll to enter copy mode.

## Other

| Keys | Action |
| --- | --- |
| `PREFIX r` | Reload the config |
| `PREFIX ?` | List all key bindings |
| `PREFIX :` | Command prompt |

## Settings worth knowing

Mouse on, status bar at the top, 50 000 lines of history, `escape-time 10` (no
lag leaving insert mode in Neovim), true color and hyperlinks in kitty, window
numbers auto-renumber when one closes.
